
# n8n Google Sheets to Gmail Automation

## Project Overview
An automated workflow that reads records from Google Sheets, formats them into an email, and sends the email using Gmail.

## Technologies
- n8n
- Google Sheets
- Gmail
- JavaScript
- Code Node

## Workflow
1. Manual Trigger
2. Google Sheets - Get Rows
3. Code - Build Email
4. IF - Sheet Has Data
5. Gmail - Send Summary

## Features
- Automated Google Sheets data extraction
- Structured email subject and body
- Multiple records supported
- Empty sheet validation
- Automated Gmail delivery

## Setup
1. Import workflow JSON into n8n.
2. Configure Google Sheets credentials.
3. Configure spreadsheet ID and sheet name.
4. Configure Gmail credentials.
5. Set recipient email.
6. Execute and verify.

## Security
Never upload API keys, OAuth tokens or credentials to GitHub.
